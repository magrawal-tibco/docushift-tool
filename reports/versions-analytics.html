DocuShift catalog — what is in scope, and when it shipped

Read live from config/products.csv and config/versions.csv. A version is convert-eligible when the pipeline will process it and archived when it is kept for the record only; a product is in scope when the catalog intends to publish it at all. Where a version has been extracted and converted, the catalog also records how many files went in and how many came out.

Point the page at the two CSVs

This page holds no copy of the data — it reads the files, so the charts always match whatever is on disk. A browser will not let a file:// page read its neighbours, so either serve the repo (python -m http.server from the repo root, then open /reports/versions-analytics.html) or drop products.csv and versions.csv here.
