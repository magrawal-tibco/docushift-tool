### Phase 36: `toc.yml` Speaks html-to-md's Dialect — **Complete, 2026-10-02**

**Why.** A side-by-side comparison of every `toc.yml` both tools produced (2026-10-02) found the two trees agree and the files do not. Of the 36 DocuShift version TOCs, 12 have a predecessor counterpart (ActiveSpaces ×6, EMS ×6). Across those 12, every shared page sits at the same depth under the same parent in the same order (306–827 shared entries per version). The disagreement is the dialect: html-to-md writes `docs_list_title` / `docs` / `url` / `subfolderlist` in all 1,339 of its TOCs, and DocuShift writes `items` / `path` / `children`. **The user has decided DocuShift adopts html-to-md's field names.** The structural decisions stay DocuShift's own, by the user's call: one TOC per version (not one per doc class), the landing / legal / support / Unfiled nodes kept, and the documents and archives stages unchanged apart from their field names.

The comparison also found two DocuShift bugs, fixed here because they show in the same files:

1. **The legal-page test matches ordinary prose.** `is_legal_label` accepts any label containing "third party" or "legal". The tail picker walks the TOC in order and takes the first hit, so "Using the ActiveSpaces JDBC Driver With Third-Party Tools" (all 6 ActiveSpaces versions) and "Integrating with Third-Party Products" (all 6 EMS versions) are taken as the legal page and moved out of their chapter to the bottom of the TOC — **12 of 36 TOCs visibly**, plus Runtime Agent 5.12.2/5.12.4 picking "Third-Party Libraries", with nothing reported. The real legal page, already at the top level, stays put, so the support page also lands out of order. Across the predecessor cache the same misfire hits **65 of 953 Flare roots**.
2. **Labels keep the source's padding.** ActiveSpaces 4.10.x TOC labels carry trailing spaces (`"Requirements "`, `"Installing on Windows "`, 8 per version) straight from the Flare TOC. html-to-md trimmed them. Reframe copies them through into `reframed/`.

What the comparison found that is **not** in scope: html-to-md dropping EMS's C and COBOL Reference (514 topics in the source TOC) and replacing ~90 content-bearing container topics with blank `_section_*.md` stubs — DocuShift is right in both; ActiveSpaces 5.2.0's one missing page (`Using-XGF-Recovery-Points`), which is source drift between a June package and the predecessor's September cache, not a converter fault; and Silver Fabric Enabler 1.2.0 publishing its doc set twice (`html/Tib_sfas_*` and `Tib_sfas_*`), a separate WebWorks bug recorded in `open-issues.md`.

#### Decisions

| decision | choice | why |
|---|---|---|
| **Field names** | `items` → `docs`, `path` → `url`, `children` → `subfolderlist`, plus a top-level `docs_list_title` | The user's call. html-to-md carries `docs_list_title` in 1,339 of 1,339 TOCs, so a file without it would still not match the dialect |
| **`docs_list_title` value** | html-to-md's values, verbatim: `Online Help` for the version TOC; `User Guides (PDF)`, `Release Information`, `Reference Documents` for the three document TOCs; the product name for the archives TOC | The user's call (2026-10-02), over a product + version proposal. The document value is a TOC-only label: `DOC_CLASS_LABELS` keeps `User Guides` for the index heading, so `User Guides (PDF)` lives beside the templates rather than replacing it |
| **Every generated `toc.yml` changes, not just the version TOC** | `toc.yml.j2`, `documents_toc.yml.j2`, `archives_toc.yml.j2`, and Reframe's `retarget` | Phase 9's rule: one shape for every generated `toc.yml`. A published repository holding two dialects is the variance Reframe's adapter seam exists to absorb, not to create |
| **Reframe reads both dialects, writes one** | A `DocsUrlSubfolderlist` adapter registers beside `ItemsPathChildren`; `retarget` emits the new shape only | `output/` trees on disk stay in the old dialect until they are reconverted, and failing Reframe on them in the meantime buys nothing. The old reader is the seam working as designed (`reframe/toc.py`); the writer has one target, as its docstring already argues |
| **Fragments stay in `url`** | A merged section is `url: "page.md#anchor"`, exactly as `path` carried it | Only the key changes. The `#` remains the signal that a node is a section and must not become its own page; `TOC_HEADER` is reworded to say `url` |
| **Legal test** | A legal *notice*, not a word: match `legal` together with `notice`, or `third party notice`, or `copyrigh`. Drop the bare `legal` and bare `third party` alternatives | Measured over all 953 Flare TOCs in the predecessor cache: the current test picks a content topic over the real `Legal and Third-Party Notices` in **65 roots** ("Third-Party Licenses for the Container Image" 26, "Required Third-Party Products" 13, the ActiveSpaces JDBC topic 6, …), and the strict test picks the real page in all 65. Bare `legal` misfires too — `CLIENT.ILLEGAL_PUBLISH`, `Legal Characters`, `addLegal()`, and Streaming's `Legal State Transitions Shown in LVTables`, which narrowing only `third party` would have promoted. In 4 roots the strict test finds nothing where the old one found something, and all 4 old picks were content topics (`cve.htm` ×2, `Third Party Libraries`, `CLIENT_ILLEGAL_PUBLISH`); those now report `TAIL_PAGE_MISSING`, which is the truth. Over the 36 converted TOCs the strict test picks the right page in all 36, including Runtime Agent 5.12.2/5.12.4, which today pick `Third-Party Libraries` |
| **Label trimming** | `strip()` the label where `navigation._rows` renders it | One point covers all four engines and both Reframe's input and output. Trimming in `flare_toc` alone would leave the same padding reachable from DITA and WebWorks labels |
| **Value-level TOC rewrite** | `converter/driver.py`'s `_TOC_PATH` regex matches `url:` | It rewrites destinations in place to keep a re-convert diffable; it must follow the template's key or it silently rewrites nothing |

#### Steps

1. **Templates and renderer.** The three `toc.yml` templates, `render_toc`'s `docs_list_title` argument, `_TOC_PATH`, the label `strip()`. Tests in `test_navigation`, `test_converter`, `test_documents`, `test_archives`, `test_distributor`, `test_dita`, `test_roots`.
2. **Reframe.** The new reader adapter (registered ahead of the old one), `retarget` writing `docs`/`url`/`subfolderlist`/`docs_list_title`, `TOC_HEADER`. Tests in `test_reframe`, including an old-dialect `output/` tree still reframing.
3. **Validation.** `validation/artifacts.py::_toc_paths` walks `docs`/`subfolderlist` and reads `url`, still tolerating the old keys so a stale tree is checked rather than passed empty. Tests in `test_validation`.
4. **Legal test.** `engines/base.py::is_legal_label`, with tests for the misfiring labels named above (both third-party topics, `Legal State Transitions…`, `CLIENT.ILLEGAL_PUBLISH`) and every legal label the corpus has (`Legal and Third-Party Notices`, `Legal and Third Party Notices`, `Important Information`/`copyrigh.htm`, `copyright.htm`).
5. **Docs.** `architecture.md` (the `toc.yml` contract and §5.1.5's tail rule), `REFRAME-REQUIREMENTS.md`'s schema note, `user-guide.md`, `open-issues.md` (Silver Fabric), `CONTEXT.md`.
6. **Regenerate once, shared with Phase 35.** `convert --force` and `reframe --force` over the converted catalog, then hand the trees to Phase 35's verification so they regenerate a single time.

*Exit: every `toc.yml` under `output/` and `reframed/` parses with top-level keys exactly `docs_list_title` and `docs`, and no row carries `items`, `path` or `children`; the comparison re-run over the 12 shared versions shows the same field names as html-to-md and every shared page at the same depth, parent and order; the two third-party topics are back inside their chapters and no TOC ends on a non-legal page; no TOC label has leading or trailing whitespace; `validate` reports no new `toc.yml` finding; the test suite and lint are clean.*

**As built (2026-10-02).** Steps 1–5 landed in one commit; step 6 is Phase 35's regeneration run. **1,738 tests pass, 2 skipped, lint clean** (18 new: the dialect, label trimming, both readers, an old-dialect tree reframing into the new one, the validator reading `url`, and 17 corpus labels pinning the legal test either way). Two things differ from the plan, both found by measuring before writing:

- **The legal test needed a third narrowing.** Dropping bare `third party` alone would have made Streaming pick `Legal State Transitions Shown in LVTables`, so bare `legal` went too (`legal` now needs `notice` or `third party` beside it). And `copyrigh` anywhere in a *label* took `Customizing the Company Logo and Copyright` in 4 roots, so it is read from the filename stem — the evidence its docstring always named — or the start of a label. Re-run over all 953 Flare roots with the shipped function: every pick is a legal notice; over the 36 converted TOCs, all 36 are right.
- **Accepting `legal` + `third party`** keeps EBX's `Legal and Third-Party` (`legal_3rdparty.htm`, 168 TOCs in html-to-md). EBX is out of scope; it is kept because nothing in the corpus misfires on it.

Smoke-checked on real data before committing: ActiveSpaces 5.2.0 converted standalone into a scratch folder gives top-level keys exactly `docs_list_title` / `docs`, 324 rows (the same row set as before), 0 padded labels, the JDBC topic back at depth 2 under *The ActiveSpaces JDBC Driver*, the tail Support → Legal as the source has it, and all 315 pages shared with html-to-md at the same depth and in the same order.

**Verified on the regenerated trees (2026-10-02)**, after Phase 35's shared run (`convert --force` for activespaces/ems/streaming/tra, `reframe --all --force`, `sync`, `validate`):

- **Dialect.** All 36 `output/` and all 14 `reframed/` TOCs have top-level keys exactly `docs_list_title` / `docs`; no row carries `items`, `path` or `children`; `docs_list_title` is `Online Help` in all 50; 0 padded labels.
- **Against html-to-md**, over the 12 shared versions: every shared page (307–828 per version) at the same depth, under the same parent, in the same order, comparing every position a page occupies (EMS 10.4.0/10.4.1 list a few pages twice; a last-position-only check reads them as 2 differences that are not there).
- **Legal tail.** Both third-party topics are back at depth 2 in their chapters in all 12. No `reframed/` TOC ends on a non-legal page; in `output/` only Designer Add-in 1.5.0 appears to, and that page *is* the legal page — `copyrigh.htm`, whose source opens with title-page text, so its title is the product name (a source quirk, unchanged by this phase).
- **Merged page counts, −1 in 13 versions, and why.** `_reframed_md_files` and `_reframed_files` fall by exactly one in EMS ×6, ActiveSpaces ×6 and Runtime Agent 5.13.0 against `9d341f7`. Each is the topic the old legal test took: once moved to the top level it was a page of its own; back in its chapter it is absorbed as a section (`concepts/the-activespaces-jdbc-driver.md#using-the-activespaces-jdbc-driver-with-third-party-tools`, `user-guide/overview/routing.md#integrating-with-third-party-products`, `…/installed-components/overview.md#third-party-libraries`). **Runtime Agent 5.13.0 had the misfire too** (`Third-Party Libraries`), which the "ends on a non-legal page" count in *Why* could not see — so the bug reached 13 of the 14 merged versions, not 12. Administrator 5.13.0, which never misfired, is unchanged.
- **`validate`**: 0 errors; of its 661 warnings (537 `ANCHOR_MISSING`, 124 `REDIRECT_SHADOWED`) none is in a `toc.yml`.
