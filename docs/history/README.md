# docs/history — the archive

Read on demand, never by default. Nothing here is kept up to date. It is the record.

| file | what it holds |
|---|---|
| [`ledger.md`](ledger.md) | `CONTEXT.md`'s decision ledger and workstream history up to 2026-10-02, verbatim |
| [`phases/`](phases/) | One file per finished phase, moved verbatim from `docs/planning.md`. The index is in [`planning.md`](../planning.md#finished-phases) |

Searching is cheaper than reading: `grep -n "<term>" docs/history -r` finds the
phase that decided something, and a reader opens only that file.
